Research demo for issue #2. Every martyria here is a two-character string — a note letter plus a genus (ichos) sign — rendered in a single run. The font stacks and centres the two through OpenType mark-to-base positioning; nothing is positioned by this page. See MARTYRIA-COMPOSITION.md next to this file for how that works.

2. Which side the letter goes on

The issue notes that “the note letter may appear on either the top or the bottom of the martyrium”. In SBMuFL that is not a free choice per martyria — it is decided by the octave register of the note letter, because each base glyph carries only one attachment anchor:

  • Low-octave letters (…Low) carry a martyriaTop anchor, so they take the …Above marks: sign on top, letter underneath.
  • Middle- and high-octave letters carry a martyriaBottom anchor, so they take the …Below marks: letter on top, sign underneath.

Pair a letter with the mark from the wrong set and there is no matching anchor, so the shaper leaves the mark unattached at the origin — it collides with the letter. The grid below shows both pairings for every letter so you can see the rule hold; the pink cells are the mismatches.

3. The martyries of the Romanian textbook

From Cursuri de Teoria Muzicii Psaltice, pp. 80 and 83. The book defines a martyria as two superposed signs — “one above, the initial of a note on the scale; the other below, placing that note in one of the nodes of a genus (diatonic, chromatic or enharmonic)”. The Greek initials it lists are Ν (Νη/Ni), Π (Πα/Pa), δ (Βου/Vu), Γ (Γα/Ga), Δ (Δι/Di), Κ (Κε/Ke), Ζ (Ζω/Zo), Ν′ (Ni′).

The book’s Zo and Ni rows carry the “de jos” / “de sus” (lower / upper) pair, which is exactly SBMuFL’s low-register vs. high-register letter — and note that the “de jos” forms are the ones drawn with the letter underneath. Use the selector to change the genus sign applied across the scale.
