This means that Generic has the free form text naming notes at the right and Byzantine mode replaces it with the two slots / wells for Fthora and Martyria which show their corresponding pickers. - (c) Martyria Picker. Echos list should be renamed to Notes. Reverse the lists, Notes on the left and Genus on the right. The user is expected to select a Note first and when he does that, the compatible Genus symbols are showed at the right at the top of the list taken from `modes-table.html` in the order of the table columns. After this symbols a horizontal separator follows and after it, all other symbols are listed, which do not appear in the table and result in uncommon combinations. The user is also allowed to select no genus symbol, causing only the note name to be displayed in the chart (this is the default). When Done is clicked on the picker and the martyria is applied, the martyries for other scale degrees are also affected by applying the Byzantine note names in sequence. For example, if you select Ni for the second degree, the first will be automatically assigned to Zo, the third to Pa, the fourth to Vou etc. Adding a new note will have next note name as martyria, without genus. The genus symbols are not affected by this automatic note assignment. If the neighboring degrees wells are filled, the genus symbols are kept, if they are not, they will get filled with empty genus (only note names).
