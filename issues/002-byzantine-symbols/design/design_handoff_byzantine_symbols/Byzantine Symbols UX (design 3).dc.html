3Byzantine symbols in the scale chart · issue #2
What this is

A Byzantine notation mode for Music Scale Plot. Cumulative cents on every note row and every separator; no free-text note name at all in Byzantine mode — the martyria is the name. Wells mirror the chart geometry, both 34×34 so the row reads evenly. Empty wells carry a mark that says which sign they insert. Every control from the shipped app is back: Base Note, Interval Type, Divisions, Mode, the interval row with its cents readout, label and colour swatch, and the Style / Orientation / Zoom toolbar.

Pickers, as specified

Fthora opens one flat set — 13 standalone fthores plus 3 chroes, E1D0–E1DF. Martyria opens two sets side by side — Genus (E170–E17B) and Echos note letter (E130–E144) — plus an octave switch and a live composed preview. Every row carries its codepoint.

Real glyphs, real codepoints

Both faces load from the SHA-pinned jsDelivr URLs in FONTS.md, and every symbol is its actual SBMuFL codepoint. One correction to the doc: the mark/mkmk anchors do not fire in the browser for PUA codepoints — measured, the zero-advance mark lands at the pen after the letter, not over it. So the martyria is composed on FONTS.md's fallback path instead: both ink boxes measured, mark centred on the letter and lifted clear of its top. Worth re-verifying in canvas before the doc's one-fillText claim is built on.
